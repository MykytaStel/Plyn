# Plyn i18n (Ukrainian + English UI) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every UI string in Plyn is available in Ukrainian and English, switchable in Settings, with Ukrainian as the default.

**Architecture:** Typed dictionaries in `src/i18n/` (`uk.ts` is the source of truth, `en.ts` must match its shape, checked by the compiler), plus small `Intl`-based helpers and a `useI18n()` hook bound to the settings store. `src/core/` stays i18n-free: it returns ids, dates and error codes, and the UI turns them into text. A guard test with a shrinking "pending" list drives the migration file by file.

**Tech Stack:** React 19, TypeScript strict, Zustand, Vitest (Node env), `Intl.PluralRules` / `NumberFormat` / `DateTimeFormat`. No new dependencies.

**Spec:** `docs/superpowers/specs/2026-11-26-i18n-design.md`

## Global Constraints

- `type Locale = 'uk' | 'en'`. The default is always `'uk'`. No browser-language detection.
- No new runtime dependencies. Both dictionaries are bundled (no lazy loading).
- `src/core/` must not import from `src/i18n/`, `src/store/` or React.
- The language switch lives only in Settings, as the last row. Label `Мова · Language`, options `Українська` | `English` (endonyms, never translated).
- Reader behaviour (hyphenation `lang`, TTS voice, fonts) follows the **content** language, never the UI language.
- English copy is native product copy: calm, short, "you", no pressure or guilt. Not literal translation.
- The worker keeps its Ukrainian `error` field for one release next to the new `code`.
- Ship as one release. `main` deploys to production, so work on branch `feature/i18n` and merge only when Task 11 is done.
- `npm test` and `npm run build` pass at the end of every task.

## Review Focus

1. **Switching language with the reader open** (or a sheet open) re-renders immediately and keeps the current card. Test in Task 1 (store), manual check in Task 11.
2. **Ukrainian plural edge numbers** 11–14, 111, 21, 22, 25 pick `many`/`one`/`few` correctly. Test in Task 1.
3. **Settings saved by v0.16** (no `language`) or holding an invalid value (`"de"`, `42`) load as `'uk'`, and `updateSettings({ theme })` does not drop `language`. Test in Task 1.
4. **Ukrainian text read in the English UI** gets `lang="uk"` on the card (Ukrainian hyphenation) and a `uk-UA` TTS voice. Test in Task 2.
5. **An old cached client calling the new worker** still shows a readable message (the `error` field is still present). Test in Task 6.

**Interfaces:**
- Produces:
  - `src/i18n/types.ts`: `type Locale = 'uk' | 'en'`; `type PluralForms = { one?: string; few?: string; many?: string; other: string }`; `type Messages` = deep shape of `typeof uk`, with string leaves widened to `string` and plural leaves (objects with `other`) widened to `PluralForms`.
  - `src/i18n/locales.ts`: `LOCALES: readonly Locale[] = ['uk', 'en']`; `LOCALE_NAMES: Record<Locale, string> = { uk: 'Українська', en: 'English' }`; `isLocale(v: unknown): v is Locale`.
  - `src/i18n/index.ts`:
    - `format(template: string, values: Record<string, string | number>): string`. Replaces `{name}` and leaves unknown placeholders untouched.
    - `plural(forms: PluralForms, count: number, locale: Locale): string`. Selects via `new Intl.PluralRules(locale)`, falls back to `other`, and substitutes `{count}` with `formatNumber(count, locale)`.
    - `formatNumber(n: number, locale: Locale): string`
    - `formatWeekdayShort(date: Date, locale: Locale): string` (`Intl.DateTimeFormat(locale, { weekday: 'short' })`)
    - `getMessages(locale: Locale): Messages`
    - `interface I18n { locale: Locale; m: Messages; format: typeof format; plural(forms: PluralForms, count: number): string; number(n: number): string }`
    - `getI18n(locale: Locale): I18n`; `currentI18n(): I18n` (reads `useSettingsStore.getState().language`, for non-React code); `useI18n(): I18n` (subscribes to `s.language`).
  - `UserSettings.language: Locale`; `DEFAULT_SETTINGS.language = 'uk'`.
  - Dictionary seed: `common.untitled` (uk `'Без назви'`), `common.cards: PluralForms` (uk one `'{count} картка'`, few `'{count} картки'`, many `'{count} карток'`, other `'{count} картки'`; en one `'{count} card'`, other `'{count} cards'`). Later tasks add their own namespaces.
