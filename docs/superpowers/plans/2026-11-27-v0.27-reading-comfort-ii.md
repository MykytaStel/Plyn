# 0.27 Reading comfort II Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** This plan ships Plyn 0.27. Settings become a short list of sections (option B). Time left uses the reader's own pace. Thoughts from a session are easy to find and export to Markdown. A design pass fixes what looks broken on a phone. Ukrainian syllable hints ship too, if EXP-03 passes.

**Architecture:**
- Pure logic goes in `src/core/`: pace, time left, thoughts Markdown and syllables.
- Storage changes are additive: two settings fields with defaults, and an optional stats field written by the existing atomic `recordProgressDelta`.
- Settings stays one bottom sheet with a section state (`null` = first screen), split into one file per section.
- EXP-03 runs on its own branch and merges into the release only if the owner says yes.

**Tech Stack:** React 19, TypeScript strict, Zustand, Dexie, Vitest (node + dom), Playwright.

**Spec:** `docs/superpowers/specs/2026-11-27-v0.27-reading-comfort-ii-design.md`. Read it first: this plan argues from it.

## Global Constraints

- Release branch `feat/v0.27` from `main`. EXP-03 branch `exp/03-syllable-hints` from `feat/v0.27` after Task 1.
- AGENTS.md invariants hold:
  - progress is a char offset;
  - new settings fields only, in `plyn_settings_v1` with defaults;
  - no Dexie version bump;
  - backups stay `schemaVersion` 2, plus the new fixture `spec/backups/v2-0.27.json`;
  - `src/core/` has no DOM, React, storage or copy.
- Every string goes in `src/i18n/locales/uk.ts` and `en.ts`. Plurals go through `plural()`. `noHardcodedCyrillic` stays green.
- Copy: calm, "ти", no pressure, no comparisons ("faster than usual"), no claims of a proven effect.
- Defaults: `syllableHints: false`, `showTimeLeft: true`.
- Pace:
  - calm default 180 wpm (`CALM_WORDS_PER_MINUTE`);
  - personal pace used from 20 samples;
  - clamp 60–600 wpm;
  - a sample needs ≥ 1500 ms on the card, and its time is capped at 3× the expected time;
  - no sample while listening or while the page is hidden.
- Time over 60 minutes shows whole hours. In a document with chapters, the reader header measures to the end of the current chapter.
- New sheets and views: `role="dialog"`, `useDialogFocus`, `useBackLayer`. A pixel change updates the visual snapshots in the same PR, on purpose.
- Before every commit: `npm run lint && npm run typecheck && npm test && npm run build`. Before the PR: `npm run test:e2e`.
- Conventional commit prefixes, one logical change per commit. Never commit `.superpowers/`, `.claude/launch.json` or `dist/`.

## Review Focus

1. **Settings opened from the reader:** restore must not appear, and saving a backup must not disturb the open document. Test in Task 7.
2. **Pace with a hidden tab or a phone put down:** a card left open for 10 minutes must not drag the pace down by more than one capped sample. Tests in Task 2 (cap) and Task 3 (`visibilitychange` resets the dwell start).
3. **A book whose current card is in the last chapter, or a book with chapters but the reader is before the first chapter offset:** time left must measure to the end of the text, or to the first chapter, never show 0 or a negative. Test in Task 2 (`chapterEndIndex`).
4. **A backup from 0.26 (no `readingPace`, no new settings) restored on 0.27, and a 0.27 backup restored where a local pace already exists:** no crash, and the pace with more samples wins. Tests in Task 1.
5. **Back gesture inside a Settings section on Android or iOS:** it returns to the first screen, and a second back closes the sheet. It never leaves the reader. Test in Task 7 (component) and Task 9 (E2E `page.goBack()`).

  - `updatePace(undefined, { words: 30, ms: 1000 })` → `undefined` (too short).
  - First sample `{ 30, 10_000 }` → `{ wordsPerMinute: 180, samples: 1 }`.
  - Paused card: with prev `{ 180, 25 }`, sample `{ 30, 600_000 }` → the time is capped at 3 × 10 s, so the sample is 60 wpm and the result is `180*0.85 + 60*0.15 = 162`, `samples: 26`.
  - Very fast: sample `{ 300, 6000 }` with no prev → clamped to 600.
  - Very slow: sample `{ 10, 59_000 }` with no prev → clamped to 60.
  - `effectiveWordsPerMinute(undefined)` → 180, `({ 240, 19 })` → 180, `({ 240, 20 })` → 240.
  - `cumulativeWords` of 3 cards with 2, 3, 0 words → `[0, 2, 5, 5]`.
  - `chapterEndIndex`:
    - with no chapters → `cards.length`;
    - current card inside chapter 2 of 3 → the index of the card that holds chapter 3's offset;
    - in the last chapter → `cards.length`;
    - before the first chapter offset → the index of the first chapter's card;
    - two chapters starting in the same card → the next card index after the current one, never ≤ `currentIndex`.
  - `minutesForWordsAt(0, 180)` → 0, `(1, 180)` → 1, `(361, 180)` → 3.
  - `toTimeLeft(0)` → `null`, `(60)` → `{ unit: 'min', value: 60 }`, `(61)` → `{ unit: 'hour', value: 1 }`, `(150)` → `{ unit: 'hour', value: 3 }` (`Math.round`; 2.5 rounds up), `(89)` → `{ hour, 1 }`.

Rules (spec § 2):
- one vowel per syllable (vowels `аеєиіїоуюя`);
- consonants between vowels open the next syllable («се-стра»);
- a sonorant `л м н р й в` right after a vowel and before another consonant closes the syllable («сон-це», «вій-сько», «мор-ква»);
- `дж` and `дз` stay together;
- `ь` and the apostrophe never start a syllable;
- case-insensitive, and the output keeps the input's case;
- a word with ≤ 1 vowel returns `[word]`.
