# 0.19.0 — Safety net I: test foundation

Status: shipped · 2026-11-26 · [roadmap entry](../../ROADMAP.md#0190--safety-net-i-test-foundation)

## Why

Readers trust Plyn with their texts and their place in them. Until 0.18, CI ran only after a push to `main` (which is also the production deploy), and nothing tested the code that writes to IndexedDB. A bug in storage, backup or the splitter would reach readers before anyone saw it.

## What

1. **Test layout.** Vitest 5 with two projects: `node` (`*.test.ts`) and `dom` (`*.test.tsx`, `*.dom.test.ts`, jsdom + Testing Library). Coverage with v8, report only.
2. **Storage (L3).** `fake-indexeddb` tests for `db.ts` (create, update, rename, remove, find by text, stats, legacy session), backup export → import, and the reader store's "reopen instead of duplicate" path.
3. **Properties (L4).** `fast-check` with a fixed seed: splitter offsets, exact slices, coverage of every character, offset round trips across card lengths; anchor tokens; sentence focus; language detection; backup validation.
4. **Static checks and CI (L0).** ESLint (hooks, a11y, floating promises), `typecheck`, and `ci.yml` on every pull request. `deploy.yml` reuses it, so a deploy needs the same green checks.
5. **Housekeeping.** Atomic stats (IMP-04), no legacy `error` text in `/api/extract` (IMP-11), Dependabot and `.nvmrc` (IMP-03), `CHANGELOG.md` (IMP-14), `spec/` fixtures for anchor, sentences and language (IMP-17).

## Findings and decisions

- **Lost stats updates.** A test firing 20 concurrent deltas got a total of 1. Fixed with a Dexie `rw` transaction.
- **Splitter offsets.** Properties found that cards were rebuilt by joining sentences with a space, then located with `indexOf`. `т.д.` became `т. д.`, was not found, and the offset fell back to a guess; a leading `?` or `…` was dropped. Approaches considered:
  1. Weaken the property to allow re-joined text. Rejected: TESTING.md says a failing property is a finding, and drifting offsets break invariant 1.
  2. Normalize the source so sentences always have one space. Rejected: it changes `charOffset` meaning for every stored document.
  3. **Chosen:** build cards from spans of the normalized text, so `card.text === normalized.slice(start, end)` always. For normally spaced text the output is identical (all existing `spec/` cases pass unchanged); only the broken cases change. New `spec/` cases pin the behaviour, with `expectedOffsets` for native apps.
- **Sentence focus** had the same leading-punctuation drop; fixed the same way (characters the pattern skips stay with the next sentence).
- **ESLint 9, not 10.** `eslint-plugin-jsx-a11y` does not support ESLint 10 yet.
- **a11y lint.** `no-autofocus` and `label-has-associated-control` are off with reasons in `eslint.config.js`. Five rules about pointer-only click targets are warnings: fixing them changes reader interaction, which belongs to the 0.28 audit, not to a release that readers should not notice.
- **Coverage for `src/features/`** is not reported as a number: v8 shows unimported `.tsx` files as 0 lines, which would mislead.

## Moved to later releases

- Sheet focus tests (open with focus inside, return focus) → 0.22, with focus management.
- Settings language-switch component test → 0.20 (CUJ-1 covers it in a real browser).
- Branch protection on `main` is a GitHub setting for the owner, not a file in the repo.
